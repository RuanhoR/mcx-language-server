# v0.0.1-alpha (2026-04-11 — 2026-05-08)

Initial development of the MCX Language Server Protocol implementation.

### Features

- **Language server** (`@mbler/mcx-server`):
  - Basic LSP server with TypeScript language service integration
  - Syntax highlighting and formatting for `.mcx` files
  - Array highlighting and bracket matching
  - MCX export handler for type resolution
  - Volar service integration for TypeScript language features
- **VSCode extension** (`mcx-vscode-client`):
  - VS Code client with activation events for `.mcx` files
  - Extension configuration and localization support

### Chores

- Added MIT License to client and server packages
- Configured build pipeline with Rollup
- Updated package metadata (version, publisher, repository, exports)
- Added `vscode-uri` as root dependency
