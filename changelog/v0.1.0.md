# v0.1.0 (2026-05-08 — 2026-05-31)

### Features

- **Script completion**: Added `provideScriptCompletions` for intelligent code completion inside `<script>` blocks — supports import statements, Minecraft events, and Event method suggestions
- **Code generation**: Server-side logic to extract event imports and build type definitions for completion context
- **Cursor position detection**: `isInsideScriptBlockContent` helper to determine cursor context
- **Image import support**: MCX language plugin enhanced to handle image asset imports
- **Improved LSP support**: Better diagnostics and hover information
