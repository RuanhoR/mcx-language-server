## Use

### Client

At vscode, download `ruanhor.mcx-vscode-client` plugin

### Cli

Run bash:

```bash
pnpm i -g mbler
```

### Server

```bash
pnpm i @mbler/mcx-server
```

```javascript
import * as mcx from '@mbler/mcx-server'
```
