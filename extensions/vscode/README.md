# MCX Language support for vscode

[Github](https://github.com/RuanhoR/mcx-language-server)

## Support

### LSP

The MCX Language Extension will automatically start LSP after installation. LSP is provided by the npm package @mbler/mcx-server.  
You can use `mcx.restart.language` command to restart lsp.

### TS Support

You can import `.mcx` file and use type. No config tsconfig.
