# v1.1.3 (2026-08-23)

### Features

- **Loot table & trade table support**: `<Component>` now accepts `<loot_tables>` and `<trade_tables>` groups. Tables emit to `behavior/loot_tables/` and `behavior/trading/` respectively; completions list the new groups and child tags (`<lootTable>`, `<tradeTable>`).

### Chores

- Bumped version from `1.1.2` → `1.1.3`
- Bundled server updated to `@mbler/mcx-server@0.1.5-rc.1` (mcx-core `0.1.3-rc.17`)
